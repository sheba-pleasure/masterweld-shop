# DEV: заказ и постоянное меню — 06.11.2026

## Изменение

После /start и /menu бот присылает постоянную ReplyKeyboardMarkup с кнопками «Меню», «Заказы», «Каталог», «Помощь», «Отмена ввода». is_persistent=true, one_time_keyboard=false, resize_keyboard=true. Inline-кнопки конкретных действий сохранены отдельно.

Навигация обрабатывается до ввода редактора, поэтому название раздела не становится названием товара. На каждый запрос снова проверяются реальный отправитель, личный чат и действующая запись сотрудника. Права задаются прежним permissions.ts.

Добавлена команда /orders. processing отображается одинаково: «в обработке». Дополнительное подтверждение требуется для выдачи и отмены; переход нового заказа в обработку выполняется сразу.

Нативный список команд около поля ввода настраивается python3 ops/dev/configure-menu.py; скрипт проверяет getMe и работает только с @testmw639bot. connect-telegram.py вызывает его при подключении DEV. Источник команд и подписей — src/lib/bot/navigation.json.
