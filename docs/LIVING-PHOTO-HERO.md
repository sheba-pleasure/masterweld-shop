Надписи «Профессиональное сварочное оборудование» внутри изображения нет. Заголовки/поиск/категории Industrial Pro сохранены поверх левой части кадра; оригинальный логотип в шапке и осциллограмма под первым экраном не менялись. Остальные цвета/компоненты сайта сохранены.

## Изображения

Три слоя подготовлены встроенным imagegen по предоставленному владельцем фото: `living-workshop-plate.webp` — широкая мастерская без знака/подписи, `living-workshop-mark.webp` — высокодетальная реконструкция отдельного знака с альфа-каналом, `living-workshop-fume.webp` — полупрозрачный пар. Это изображение по референсу, не побуквенный новый SVG. Оригинальный файл шапки не заменён генерацией. Размеры, SHA-256 и происхождение — living-workshop.asset.json. Суммарно ~768 КБ.

Исходники генерации: exec-9776b4e9-7d0e-446f-9c9b-73a611101f8b.png, exec-4bbcf42d-6d77-4e5e-a0b2-079573279993.png, exec-5b21b9f7-fc5e-4cfb-b549-c844130fc5b5.png. Использован первый пользовательский референс codex-clipboard-22e021de-565d-45c2-927c-fafbfe07badc.png. Новых сторонних фотографий/моделей нет.

## Движение

Зацикленный восьмисекундный cinemagraph: знак движется по вертикали на 7 px, поворачивается на ±0.3°, масштаб меняется на 0.6%; реагирует мягкая тень над площадкой. Две полупрозрачные струи пара сдвинуты на четыре секунды. Свет дуги слегка меняется, искры Canvas 2D следуют траектории с тяжестью/отскоком, остывают и гаснут; их периоды кратны циклу. React-состояние не обновляется покадрово. Полный кадр построен из фотографических слоёв с анимацией, не является записью реального цеха.

Пауза останавливает CSS и RAF; hidden/offscreen также приостанавливают движение. Reduced motion оставляет статичную композицию. ResizeObserver согласует кадрирование, знак и источник искр; на мобильном точка композиции адаптирована и текст остаётся читаемым. SSR имеет исходные координаты для знака до гидратации. Listener/observer/RAF освобождаются при unmount. Новых JS-зависимостей и backend-путей нет.
