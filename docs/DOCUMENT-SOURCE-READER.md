# Читать паспорт или другой исходный документ в боте

В разделе «Документы → товары» откройте обработанный файл и нажмите **«Читать текст документа»**. Выберите страницу или фрагмент. Если текст длинный, кнопка **«Продолжение текста»** открывает следующую часть. **«Скачать оригинал для сверки»** возвращает исходный файл.

Номер «Страница файла» относится к порядку страницы в PDF и может отличаться от номера, напечатанного на листе. Для Word показывается номер сохранённого абзаца, для Excel — лист. Если положение неизвестно или метки противоречат друг другу, бот прямо предлагает уточнить место по оригиналу. Он не выдаёт номер в списке за физическую страницу.

## Что проверять

- Сверьте точную модель и модификацию с товаром. Похожее название не подтверждает соответствие паспорта.
- Для распознанного скана проверьте буквы, цифры, единицы и условия измерений.
- В PDF с текстовым слоем дополнительно смотрите рисунки и таблицы в оригинале: извлечённый текст не доказывает полноту.
- Если документ обработан частично, оставшиеся страницы нужно проверить отдельно.
- Пустой текстовый блок не удаляется из списка и не подменяется соседним.

Чтение ничего не подтверждает, не исправляет, не импортирует и не публикует. Для паспорта без таблицы товаров отсутствие таблиц может быть нормальным результатом. Переделывать паспорт ради импорта не нужно. Проверка и привязка первичного документа к модели, подготовка предложений характеристик и окончательное подтверждение — отдельные действия; этот читатель сам их не выполняет.

## Доступ и сохранность

Используется прежний bot_document_intake get: действующие права import_prices + view_costs, личный чат и принадлежность документа текущему сотруднику. Продавцу доступ к чужим прайсам не открывается. Исходные байты, распознанный текст, координаты и решения остаются неизменными. Исправленные строки импорта не подменяют исходный текст.

Каждая часть сохраняет точные символы источника, включая регистр, пробелы и переводы строк. Разбиение не разрывает суррогатную пару Unicode. В Telegram отправляется одна ограниченная часть по нажатию; массовой автоматической отправки всех страниц нет. Старые ссылки адресуют прежний неизменяемый документ и индекс блока. Неверная часть не заменяется другой.

Содержимое выводится простым текстом. Предпросмотры ссылок отключены через LinkPreviewOptions.is_disabled ([Telegram Bot API](https://core.telegram.org/bots/api#linkpreviewoptions)). Встроенные в документ команды и разметка не исполняются. Техническая выгрузка JSON сохранена отдельной подписанной кнопкой для диагностики.

Схема БД, parser и worker этим изменением не обновляются. Фактическая версия приложения и учебная проверка указаны в STATUS.md и docs/VERIFICATION.md. Browser Skill и Telegram-клиент для визуальной проверки не использовались.
