# Выбор модели для будущего поиска

Функция готовится только для DEV. Фактическое применение схемы и версия приложения указаны в STATUS.md; наличие этого файла не означает развёртывание.

## Как выбрать

В карточке товара откройте «Модель и исходные документы». Под подходящим подтверждённым источником нажмите «Выбрать эту модель…». Кнопка доступна только для действующей связи с проверенной моделью.

Бот покажет выбранные производителя, модель и модификацию, исходный файл и предупреждение о других моделях в истории. Сверьте их с товаром. «Подтвердить выбор модели» сохраняет решение. «Отменить — оставить прежний выбор» отменяет только подготовленный выбор.

Выбор не меняет название, цену, наличие и публикацию товара. Он не исправляет модель в документе и не удаляет другие источники. Изменить исходные сведения можно отдельной кнопкой «Проверить модель в документе».

## Если не уверены

«Прочитать актуальный выбор модели» показывает действующее решение. «Не уверен — подготовить снятие выбора» сначала открывает подтверждение. После подтверждения модель становится невыбранной; другая модель автоматически не подставляется. История сохраняется.

Изменившиеся сведения требуют новой сверки: модель/исходная строка, относящиеся к модели поля карточки, добавление или отмена применённого источника. Изменение цены и наличия само по себе не меняет идентичность товара. Исключённый товар недоступен для поиска; выбор модели не снимает исключение.

Если подготовленный выбор устарел или истекли 15 минут, откройте источники заново. Старая кнопка не подтверждает изменившиеся данные. Повтор уже сохранённого решения показывает квитанцию и текущий выбор; он не возвращает прежнюю модель поверх нового решения или снятия выбора.

## Если ответ не пришёл

Нажмите «Прочитать сохранённый результат». Бот читает ту же квитанцию, а не отправляет подтверждение повторно. Ошибка чтения не означает отсутствие решения. Незавершённый вопрос другого редактора нужно сначала закончить или отменить.

## Права и границы

Доступны только администратор и директор с повышенными правами, в личном служебном чате. Продавцам право импорта/выбора модели не выдаётся. Уполномоченные администраторы видят общий выбор модели товара; исходные документы и их подробности доступны только владельцу соответствующих файлов. Новый выбор можно подготовить из собственного проверенного источника.

Поиск в интернете, автоматические характеристики, описания и генерация фотографий пока не подключены. Эта функция сохраняет проверяемое решение для следующего этапа, а не объявляет его реализованным. Будущий обработчик обязан заново проверять актуальность выбора перед использованием и перед сохранением результатов.

## Техническая проверка

0033 добавляет закрытые product_model_choices и product_model_selection и одну служебную RPC. Подготовка связана с устойчивым ID исходного нажатия, подтверждение и аудит атомарны. Сохранённый набор свидетельств охватывает действующие источники разных владельцев; совпадение артикула само по себе не выбирает модель. Текущее состояние вычисляется по фактическим сведениям, а не по одному сохранённому флагу.

Guarded runner проверяет DEV identity и точные базовые функции, выполняет изолированную репетицию на учебных данных и применяет добавление в одной транзакции. Значения всех прежних публичных таблиц и закрытые права проверяются до COMMIT. Отдельных резервирования, внешней загрузки и изменения расписаний нет — это учитывает указание владельца прекратить отдельную работу над бэкапами. Production не затрагивается и требует отдельной проверки перед выпуском.
