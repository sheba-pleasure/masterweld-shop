# Новый интернет-магазин shop.masterweld.ru с управлением через Telegram-бота

## Главное правило
Старый masterweld.ru не трогаем: URL, карточки, sitemap, robots, индексирование и поисковую видимость сохраняем без изменений. Баннеры и ссылки со старого сайта на магазин — только после отдельного согласования, без автоматической замены контента. Интернет-магазин «Мастер Сварщик» закрыт от индексации до отдельного письменного решения владельца; защиту сохраняем и при переносе на свой сервер.

## Часть 2. Магазин shop.masterweld.ru
Витрина:
- Главная, каталог с разделами и фильтрами (цена, бренд, наличие, характеристики), поиск, карточка товара с галереей фото.
- Корзина и оформление заказа.
- Личный кабинет покупателя: вход, история и статусы заказов, адреса.
- Доставка: самовывоз и курьерские службы (СДЭК и аналоги) с расчётом стоимости.
- Онлайн-оплата картой через российскую платёжную систему (ЮKassa, Т-Касса или аналог). Встроенные Stripe и Paddle для продавца из РФ не подходят. Нужен договор магазина с платёжной системой.
- Современный аккуратный дизайн в фирменном стиле MasterWeld, удобный с телефона.

## Часть 3. Telegram-бот для сотрудников
Доступ только у сотрудников из списка, который ведёт администратор.

Возможности:
- **Товары:** создать, изменить, скрыть, удалить. Бот ведёт пошаговый диалог: название → раздел → цена → наличие → фото.
- **Фото:** сотрудник отправляет фото, и оно прикрепляется к выбранному товару. Можно задать главное фото и порядок.
- **Цены и наличие:** быстрые команды, например «цена 12345 — 18 990».
- **Разделы каталога:** создать, переименовать, переместить.
- **Заказы:** новые заказы приходят в общий рабочий чат. Статус меняется кнопками: принят, собран, отправлен, выдан, отменён.
- **ИИ-помощник:** по названию и характеристикам пишет описание товара и создаёт картинки. Перед публикацией сотрудник их подтверждает.

Загрузка файлов с прайсами:
- Принимает Excel, CSV, PDF, Word, фото прайса.
- Распознаёт строки: артикул, название, бренд, цена, остаток.
- Сопоставляет с каталогом. Сначала по артикулу, затем по бренду и модели, затем по похожему названию.
- Перед применением показывает сводку: «обновить цены: 120, новых товаров: 15, не распознано: 4». Ничего не меняется, пока сотрудник не нажмёт «Применить».
- Найденные товары обновляет. Ненайденные создаёт как черновики карточек, при желании сразу с описанием от ИИ. Следующий файл с теми же реквизитами обновит уже созданную карточку, а не создаст дубль.
- Сохраняет историю загрузок и позволяет откатить последнюю.

## Технические детали
- Данные и фото хранятся в Lovable Cloud: товары, разделы, фото, заказы, сотрудники, история импорта. Права доступа настраиваются на уровне строк базы.
- Бот получает обновления через вебхук на публичный адрес. Заголовок с секретом проверяется. Запись в базу идёт только для сотрудников из списка.
- Разбор файлов и ИИ-описания работают через Lovable AI. Сопоставление товаров использует нормализованный ключ (бренд + модель + артикул). Каждый импорт создаёт снимок изменений, чтобы его можно было откатить.
- Canonical сейчас **не реализован**, его нельзя считать настроенным. По READ-ONLY аудиту кода 26.10.2026 в root установлен `noindex, nofollow`; фактическая отдача роботам и состояние индекса UNKNOWN. Самостоятельность карточек и дубли требуют сопоставления URL/контента, а не предположения об отсутствии дублей.

Заменять URL только нового магазина после тестов и отдельного разрешения; не придумывать и не перерисовывать фото/свойства товара.
